# Original native application placeholder

`icon0.svg` is newly authored rectangle-only lettering and geometric shapes for
this project's **Parasite Eve 3** native development label. The five-by-seven
letterforms and arrangement were specified directly for this source; no font,
Square Enix art, game icon, screenshot, PE1 art or external image was imported.
The text identifies this development project and is not an official game logo.

The source and renderer were written with Codex assistance. The original asset
and `render_icon.py` are MIT licensed under the accompanying `LICENSE.txt`.
Original game names and rights are not relicensed by this asset notice.

Run `python runtime/assets/ps5/render_icon.py` to rasterize the bounded SVG into
`icon0.png`. The renderer uses only Python's standard-library XML, integer raster
operations and PNG/zlib encoding. It emits opaque 512x512,8-bit RGB, noninterlaced
PNG without timestamps or platform fonts. The SVG is the editable source.

This is a functional original placeholder, not remastered game artwork. Its
presence satisfies the manager's mandatory icon-file packaging requirement;
actual console registration and visual appearance remain human qualification.
